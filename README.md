# María, Maríaaaa 💜

A small Valentine's invitation I made for my girlfriend—just a personal project, some JavaScript, and a couple of cat GIFs.

## What's inside

A single page with a Valentine's question, Yes/No buttons, and a little celebration when she says yes.

Built with plain **HTML, CSS, and JavaScript**, with no build tools or backend.

## Open it

Clone or download this repository, then open [`index.html`](index.html) in your browser. No installation is needed.

The cat GIFs are hosted on Tenor, so you'll need an internet connection to see them.

## Files

- [`index.html`](index.html): invitation, inline styling, and interaction code.
- [`script.js`](script.js): invitation response handler, also defined inline in the HTML.
- [`styles.css`](styles.css): a separate stylesheet; the current HTML uses inline styles rather than linking this file.

Made for María, with love.
